# Atalhos

Frases que aparecem como chips acima do campo quando ele está vazio. Tocar num chip
envia a mensagem na hora.

Um atalho por linha, no formato `- rótulo :: texto enviado`. Sem `::`, o texto serve
também de rótulo. O rótulo é o que cabe no chip; o texto é o que o conselheiro recebe.

Editar este arquivo e recarregar a página no celular já pega a mudança.

- breve :: seja breve, me dá só a conclusão
- e aí? :: o que você acha disso?
- agora? :: vale a pena mexer nisso agora ou deixo pra depois?
- risco :: qual o risco que você vê aqui?
- celular :: estou no celular, responda curto
- sem rodeio :: responda direto, sem recapitular o que eu disse
